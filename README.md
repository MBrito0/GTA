# 🌆 Dev City - Seleção de Personagens (Estilo GTA com IA)

> *"Não é só um jogo..."* 🎮✨

Bem-vindo ao repositório oficial do **Dev City**! Este projeto é uma página web interativa inspirada na estética de jogos de mundo aberto, desenvolvido durante a **Missão Programação do Zero com IA** do **DevClub** (com o professor Rodolfo Mori). 

O grande diferencial deste projeto é a integração com **Inteligência Artificial (Puter.ai)**, permitindo que o usuário faça upload de uma foto própria do computador e se transforme em um personagem jogável em tempo real!

---

## 🚀 Funcionalidades

- **Seleção de Personagens:** Escolha entre lendas clássicas de Dev City.
- **Transformação por IA (Selfie to Character):** Envie sua foto e deixe a inteligência artificial transformar você em um personagem de videogame com contornos marcantes e cores vivas estilo GTA.
- **Interface Dinâmica:** Manipulação de DOM via JavaScript para atualizar avatares e nomes fluidamente.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3:** Estrutura e estilização visual com temática de jogos.
- **JavaScript (ES6+):** Lógica de manipulação de elementos e integração de arquivos (`FileReader`).
- **Puter.js & IA (OpenAI / Replicate):** Processamento de imagem e geração de arte automatizada (`puter.ai.txt2img`).
